How it works

Three steps. One file. Any browser.

Scan and choose

One click reads what this browser can move. Switch off anything you want to leave behind.

Lock it down

Encrypt the bundle with a passphrase you choose. Without it, the file is unreadable.

Import anywhere

Open Portage in the other browser, drop the file in, and watch everything come back.

Why Portage

Everything that matters. Nothing that doesn't.

Built on the official browser APIs, so it only touches data it can actually move, and says so when it can't.

Encrypted with your passphrase

Your bundle carries sign-in cookies, so Portage treats it like a password vault. Encryption is on by default, and the passphrase only ever lives in memory.

What actually transfers

CookiesIncluding partitioned cookiesRe-set so you stay signed in
Open tabsEvery windowReopened in this window
Recently closedTabs and windowsReopened as tabs
