For testing a release before it reaches the store, or for browsers without store access.

Download .zip
How to load it unpacked
  1. Unzip the download somewhere you'll keep it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the folder that contains manifest.json.

Unpacked builds don't update on their own. Remove it before installing the store version.

Firefox

Firefox 115 and newer, including ESR
Get the add-on
  • Installs from Firefox Add-ons and updates itself
  • Keeps history titles and visit times on import

Latest build (unpacked)

checking…

For testing a release before it reaches Add-ons. Firefox removes temporary add-ons when it restarts.

Download .zip
How to load it temporarily
  1. Unzip the download somewhere you'll keep it.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on… and pick manifest.json from the unzipped folder.

The add-on stays until Firefox restarts. Use the Add-ons version for everyday use.
